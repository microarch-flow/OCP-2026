# LLR/CBFC 测试：交换机全通过不等于端点全通过

## 核心结论
链路重传和信用流控的正确性必须靠故障注入、最小帧/最长距离、incast 和状态可观测性联合测试。材料有真实测试结果，但交换机与预硅端点是两套不同完成度，不能合并成整个生态已互通。[[networking/Standardizing Ethernet Scale-Up Validation- Test Strategy and Current Progress on LLR-CBFC.pdf#page=6|PDF p.6]][[networking/Standardizing Ethernet Scale-Up Validation- Test Strategy and Current Progress on LLR-CBFC.pdf#page=7|PDF p.7]][[networking/Standardizing Ethernet Scale-Up Validation- Test Strategy and Current Progress on LLR-CBFC.pdf#page=15|PDF p.15]]

## 关键证据、指标与条件
- 交换机方案为 Alibaba scale-up switch 与 Keysight INPT800，图示 4×400GE、800G→2×400G 10m AOC；22用例全部通过。[[networking/Standardizing Ethernet Scale-Up Validation- Test Strategy and Current Progress on LLR-CBFC.pdf#page=10|PDF p.10]][[networking/Standardizing Ethernet Scale-Up Validation- Test Strategy and Current Progress on LLR-CBFC.pdf#page=11|PDF p.11]]
- LLR-09 另注明 20m cable、无链路错误、64–9216B：L1 约99.61%（存在控制开销），switch cut-through 299–330ns；含线缆/收发器端到端650–710ns。不能拿 switch-only 当系统时延，也没有 p99。[[networking/Standardizing Ethernet Scale-Up Validation- Test Strategy and Current Progress on LLR-CBFC.pdf#page=12|PDF p.12]]
- LLR-10 注入 FEC error：示例 LLR 0丢失，非LLR丢3帧；正文说 application latency “increased over1200ns”，未清晰区分增量/绝对值，保留措辞而不强行相加。[[networking/Standardizing Ethernet Scale-Up Validation- Test Strategy and Current Progress on LLR-CBFC.pdf#page=12|PDF p.12]]
- 3:1 incast 的 lossless VC 无丢失、best-effort 有损；信用上限随距离/帧大小变化：500m单程/5µs RTT，64B需7825、9216B需6240；10m/100ns分别1990/1875，**credit 单位未给出，不是字节**。[[networking/Standardizing Ethernet Scale-Up Validation- Test Strategy and Current Progress on LLR-CBFC.pdf#page=13|PDF p.13]]
- 通常 CtlOS 开销约0.38%；port-level共享信用不提供VC隔离。不同距离须调 Credit Limit、Outstanding_Data/Seq_Max。[[networking/Standardizing Ethernet Scale-Up Validation- Test Strategy and Current Progress on LLR-CBFC.pdf#page=14|PDF p.14]]

## 图表与架构
已核 p.12/13 计数、延迟与 incast；p.15 是 UniVista 预硅平台，经 <10Gb/s 侧到 speed adapter，再到2×400GE仪表。LLR10/10，CBFC9/12：IPv6未支持，两个incast待三方联测，不能宣称端点400G原生满速完成全部用例。[[networking/Standardizing Ethernet Scale-Up Validation- Test Strategy and Current Progress on LLR-CBFC.pdf#page=15|PDF p.15]]

## 关联与比较

## 不确定性与待验证
需明确最长距离是真实光纤还是延迟模拟、各测试运行时长、错误模式、poison CRC与cut-through行为。材料未给整柜多跳死锁、故障串扰或推理负载测量；“lossless”只在测试条件内成立。
