# CoSERV：把供应链背书与参考值分发给异构Verifier

> 阅读范围：已阅读本文件全部可提取文字（14页）。未完成图表视觉核对；不把文字提取视作图形关系验证。

## 核心结论

- Confidential AI涉及CPU、加速器、固件、身份RoT等多类证据；验证者必须获取各供应链来源的背书/参考值，统一证据格式还不够。[[Security/Endorsements for Attestation- A Common Language for the Whole Supply Chain.pdf#page=3|PDF p.3]][[Security/Endorsements for Attestation- A Common Language for the Whole Supply Chain.pdf#page=4|PDF p.4]][[Security/Endorsements for Attestation- A Common Language for the Whole Supply Chain.pdf#page=5|PDF p.5]]
- CoSERV定位为查询/收集/缓存Endorsements与Reference Values的传送协议，不是新的设备测量机制；材料明确仍pre-RFC。[[Security/Endorsements for Attestation- A Common Language for the Whole Supply Chain.pdf#page=7|PDF p.7]][[Security/Endorsements for Attestation- A Common Language for the Whole Supply Chain.pdf#page=8|PDF p.8]][[Security/Endorsements for Attestation- A Common Language for the Whole Supply Chain.pdf#page=13|PDF p.13]]

## 关键证据

Veraison端到端PoC把本地验证工具、供应链artifact缓存与HTTP endorsement service相连；后续角色扩展和Arm CCA guest集成仍列Future Work，服务标Experimental。[[Security/Endorsements for Attestation- A Common Language for the Whole Supply Chain.pdf#page=10|PDF p.10]][[Security/Endorsements for Attestation- A Common Language for the Whole Supply Chain.pdf#page=11|PDF p.11]][[Security/Endorsements for Attestation- A Common Language for the Whole Supply Chain.pdf#page=12|PDF p.12]]

## 指标与条件

无供应商覆盖量、缓存命中率、参考值大小、分发延迟或服务SLA；“scalable”是设计目标。

## 图表与架构

未视觉核对架构图；仅使用文字明确的工具/缓存/服务角色，不补推信任边界。

## 关联与比较

与PLDM reference manifest分发互补：PLDM把参考值带到运营系统，CoSERV让不同Verifier按统一接口消费供应链artifact；仍须可信源和版本策略。

## 不确定性与待验证

需补撤销/过期、缓存新鲜性、离线验证、根轮换、artifact关联与不同供应链声明冲突处理。PoC不代表标准冻结。
