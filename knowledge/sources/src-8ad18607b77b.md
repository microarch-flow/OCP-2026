# 05_CLARA Automated AI cluster architecture design tool

## 核心结论
Lenovo CLARA将NetBox用作共同数据模型，自动化device配置、constraint checking、多rail/plane拓扑、floorplan与BOM；关键是保持跨机电/网络设计意图一致，不是由模型自由生成一张架构图。[[ai-clusters/05_CLARA Automated AI cluster architecture design tool.pdf#page=3|PDF p.3]] [[ai-clusters/05_CLARA Automated AI cluster architecture design tool.pdf#page=4|PDF p.4]] [[ai-clusters/05_CLARA Automated AI cluster architecture design tool.pdf#page=6|PDF p.6]]

## 关键证据
工作流缺信息时阻塞后续模块；拓扑算法node/switch-aware且只搜feasible配置。floorplan须考虑rooms/floors/columns、network/CDU/power reach与运营偏好，最后估算缆长并过滤cable/transceiver兼容性。[[ai-clusters/05_CLARA Automated AI cluster architecture design tool.pdf#page=6|PDF p.6]] [[ai-clusters/05_CLARA Automated AI cluster architecture design tool.pdf#page=9|PDF p.9]] [[ai-clusters/05_CLARA Automated AI cluster architecture design tool.pdf#page=10|PDF p.10]] [[ai-clusters/05_CLARA Automated AI cluster architecture design tool.pdf#page=12|PDF p.12]]

## 指标与条件
p.11 preliminary目标函数minC=α×network length+β×CDU length，用simulated annealing，称optimization<10min。未给cluster规模、CPU、约束数、seed、最优性gap；这不是完整美元TCO目标，也不保证global optimum。p.3 GPU+power only50%TCO引2014论文且无当代AI配置，不应当成普适成本分解。[[ai-clusters/05_CLARA Automated AI cluster architecture design tool.pdf#page=3|PDF p.3]] [[ai-clusters/05_CLARA Automated AI cluster architecture design tool.pdf#page=11|PDF p.11]]
