# Immersion Reliability Community Update

## 核心结论
材料质量、功能部件兼容与随时间变化的系统热化学可靠性是三个不同任务。社区数据库可筛选候选，不能代替独立qualification；一个coupon的腐蚀阈值也不是整机寿命阈值。[[cooling-immersion/Thermochemical-Reliability-Workstream-Update.pdf#page=2|PDF p.2]] [[cooling-immersion/Thermochemical-Reliability-Workstream-Update.pdf#page=3|PDF p.3]] [[cooling-immersion/Thermochemical-Reliability-Workstream-Update.pdf#page=6|PDF p.6]] [[cooling-immersion/Thermochemical-Reliability-Workstream-Update.pdf#page=12|PDF p.12]]

## 关键证据
- Material Compatibility v2.0在开发，新增fluid/material/end-user角色化模板、条件与limits。[[cooling-immersion/Thermochemical-Reliability-Workstream-Update.pdf#page=4|PDF p.4]] [[cooling-immersion/Thermochemical-Reliability-Workstream-Update.pdf#page=5|PDF p.5]]
- 数据库报告570 observations、95 component profiles、6 fluid families，明确community-sourced screening，independent qualification essential；不是570项独立认证。p.6官方URL仍placeholder。[[cooling-immersion/Thermochemical-Reliability-Workstream-Update.pdf#page=6|PDF p.6]] [[cooling-immersion/Thermochemical-Reliability-Workstream-Update.pdf#page=7|PDF p.7]]
- 功能server component compatibility白皮书已发布：以vendor生产验收指标判断，并同时分析进入fluid的污染物；风险优先级、soak、failure root cause互相连接。[[cooling-immersion/Thermochemical-Reliability-Workstream-Update.pdf#page=8|PDF p.8]] [[cooling-immersion/Thermochemical-Reliability-Workstream-Update.pdf#page=9|PDF p.9]] [[cooling-immersion/Thermochemical-Reliability-Workstream-Update.pdf#page=10|PDF p.10]]

## 指标与条件
Thermochemical Reliability白皮书仍development，规划failure modes→equivalent-service-life acceleration→可靠性试验→fluid/hardware degradation→风险。没有本讲已校准的寿命换算系数或通用污染阈值。[[cooling-immersion/Thermochemical-Reliability-Workstream-Update.pdf#page=11|PDF p.11]] [[cooling-immersion/Thermochemical-Reliability-Workstream-Update.pdf#page=12|PDF p.12]]
产学路线图：4Q26铜coupon sulfur/halide/TAN阈值，2Q27污染致热阻变化，3Q27 PCB EID，2Q28 system SI/DDR5与fluid寿命模型；这是计划里程碑，非完成结果。[[cooling-immersion/Thermochemical-Reliability-Workstream-Update.pdf#page=13|PDF p.13]]

## 图表与架构
p.14明确跨层链：铜coupon/化学表征→PCB resistance/leakage→DDR5 rank margin与介电shift→寿命评估。每层需要独立测量，不能越过functional reliability只凭铜照片声明系统安全窗口。[[cooling-immersion/Thermochemical-Reliability-Workstream-Update.pdf#page=14|PDF p.14]]
