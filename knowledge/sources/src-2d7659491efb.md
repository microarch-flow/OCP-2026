# Solidigm／Metrum：SSD 参与推理数据通路的五种不同收益

## 核心结论
SSD收益来自检索、KV复用、减少主存中转、跨副本共享与压缩五种机制。本文谨慎标注“不同实验”“初步测试”“内部未发表结果”，因此不能把各项加速相乘为一个总收益。[[executive-sessions/54_The New Tokenomics How Data Infrastructure Increasingly Sets AI ROI pr.pdf#page=5|PDF p.5]][[executive-sessions/54_The New Tokenomics How Data Infrastructure Increasingly Sets AI ROI pr.pdf#page=7|PDF p.7]][[executive-sessions/54_The New Tokenomics How Data Infrastructure Increasingly Sets AI ROI pr.pdf#page=16|PDF p.16]]

## 指标与条件
p.11“SSD比GPU memory快6.7×”比较的是**另一worker能从共享池复用**与没有该上下文而重算的路径，不是SSD物理读延迟小于HBM。p.13还披露恢复延迟+9.6%、host CPU约2.5×，不能把压缩当作免费容量。[[executive-sessions/54_The New Tokenomics How Data Infrastructure Increasingly Sets AI ROI pr.pdf#page=11|PDF p.11]][[executive-sessions/54_The New Tokenomics How Data Infrastructure Increasingly Sets AI ROI pr.pdf#page=13|PDF p.13]]

## 图表与架构
p.9 GDS路径跳过主存bounce，但CPU仍编排I/O。p.10共享池改变的是缓存可见域与命中，不只是介质选择；冷启动、失效、版本不兼容仍会重算。[[executive-sessions/54_The New Tokenomics How Data Infrastructure Increasingly Sets AI ROI pr.pdf#page=9|PDF p.9]][[executive-sessions/54_The New Tokenomics How Data Infrastructure Increasingly Sets AI ROI pr.pdf#page=10|PDF p.10]]

## 关联与比较

## 不确定性与待验证
