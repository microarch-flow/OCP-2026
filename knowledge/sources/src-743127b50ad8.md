# Luxshare-Zinsight Nova Link SST：直接中压转800V的集成收益与风险

## 核心结论
SST把传统变压器、UPS及AC/DC多级路径集成到中压直转DC平台；减少阶段的同时把绝缘、热、保护及容错集中到同一系统。高密度规格必须与失cell后运行、可维修性及系统边界一起审核。[[expo-hall-sessions/Direct-Medium-Voltage-to-800VDC-Conversion-for-AI-Data-Centers-presented-by-Luxshare-Tech.pdf#page=4|PDF p.4]] [[expo-hall-sessions/Direct-Medium-Voltage-to-800VDC-Conversion-for-AI-Data-Centers-presented-by-Luxshare-Tech.pdf#page=5|PDF p.5]] [[expo-hall-sessions/Direct-Medium-Voltage-to-800VDC-Conversion-for-AI-Data-Centers-presented-by-Luxshare-Tech.pdf#page=6|PDF p.6]] [[expo-hall-sessions/Direct-Medium-Voltage-to-800VDC-Conversion-for-AI-Data-Centers-presented-by-Luxshare-Tech.pdf#page=7|PDF p.7]]

## 关键证据、指标与条件
- 35kV/10MW对照：传统93.3%、188m²、24–30月；Nova98.7%、9.6m²、4月。未给等冗余/维护通道/电池设施/交期起算口径，不能直接宣称整机房面积省95%或交付必缩至4月。图中新架构BBU在SST外，特别需确认是否计入面积与成本。[[expo-hall-sessions/Direct-Medium-Voltage-to-800VDC-Conversion-for-AI-Data-Centers-presented-by-Luxshare-Tech.pdf#page=4|PDF p.4]]
- 30cell、每相10个，输入串联输出并联共800VDC。局部故障旁路及快速更换是设计响应，未给允许旁路数量、降额、故障检测时间、MTTR或现场可用率。[[expo-hall-sessions/Direct-Medium-Voltage-to-800VDC-Conversion-for-AI-Data-Centers-presented-by-Luxshare-Tech.pdf#page=6|PDF p.6]]
- 2.3kV SiC MOSFET→ZPAK模块→420kW/216L液冷cell；1.94kW/L含35kV绝缘，99.0%是**峰值cell效率**，非整套效率；225°C是模块结温能力，不是正常运行设定。[[expo-hall-sessions/Direct-Medium-Voltage-to-800VDC-Conversion-for-AI-Data-Centers-presented-by-Luxshare-Tech.pdf#page=8|PDF p.8]]
- 整套35kV/10MW液冷产品称98.7%、800/1500V输出、NEMA3R、grid-forming、SSCB及OCP SST V0.3 compliant；13.8kV/3MW风冷称98.8%、2.7m²/IP21。只记录厂商规格，未取得型式测试。[[expo-hall-sessions/Direct-Medium-Voltage-to-800VDC-Conversion-for-AI-Data-Centers-presented-by-Luxshare-Tech.pdf#page=9|PDF p.9]] [[expo-hall-sessions/Direct-Medium-Voltage-to-800VDC-Conversion-for-AI-Data-Centers-presented-by-Luxshare-Tech.pdf#page=10|PDF p.10]]
- 下一代99%/1.5MW/m²是目标，当前图1.04/1.11MW/m²。图脚注承认竞品公开数据的效率/功率密度边界不同，不用于严谨排名。[[expo-hall-sessions/Direct-Medium-Voltage-to-800VDC-Conversion-for-AI-Data-Centers-presented-by-Luxshare-Tech.pdf#page=11|PDF p.11]]
