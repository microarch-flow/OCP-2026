# NVIDIA SDK + FBOSS: Building Production-Ready AI Network Fabrics

## 核心结论
开放SAI的核心工程收益是让ASIC SDK、NOS与测试在硬件到达前并行；但功能模拟器不是QoS/物理层/尾延迟验证器。开放接口降低集成耦合，不自动消除行为差异。[[networking/06_NVIDIA SDK + FBOSS Building Production-Ready AI Network Fabrics.pdf#page=7|PDF p.7]][[networking/06_NVIDIA SDK + FBOSS Building Production-Ready AI Network Fabrics.pdf#page=8|PDF p.8]][[networking/06_NVIDIA SDK + FBOSS Building Production-Ready AI Network Fabrics.pdf#page=11|PDF p.11]]

## 关键证据
- SimX在VM内模拟PCI ASIC，支持forwarding tables/L2/L3/ACL；明确**不模拟QoS和L1协议**。[[networking/06_NVIDIA SDK + FBOSS Building Production-Ready AI Network Fabrics.pdf#page=8|PDF p.8]]
- FBOSS以unit、agent、feature、HW-facing tests作为merge门槛；供应商交付前运行测试并联合triage，API语义由测试契约补全。[[networking/06_NVIDIA SDK + FBOSS Building Production-Ready AI Network Fabrics.pdf#page=9|PDF p.9]][[networking/06_NVIDIA SDK + FBOSS Building Production-Ready AI Network Fabrics.pdf#page=11|PDF p.11]]
- 共同演进涵盖SDK-ISSU、drop原因/counters、Mirror-on-Drop/TAC、health checks与用PTP估算线缆长度。[[networking/06_NVIDIA SDK + FBOSS Building Production-Ready AI Network Fabrics.pdf#page=12|PDF p.12]]

## 指标与条件
- Spectrum-6宣称102.4 Tb/s，512×200G或128×800G；是芯片容量/功能规格，不是本文件证明无拥塞p99的结果。[[networking/06_NVIDIA SDK + FBOSS Building Production-Ready AI Network Fabrics.pdf#page=6|PDF p.6]]
- 约6周在SimX/替代平台开发与测试；Meta硬件到达约1周90%测试通过；约2季度到全通过并准备cluster qualification。后者不是“1周生产就绪”。[[networking/06_NVIDIA SDK + FBOSS Building Production-Ready AI Network Fabrics.pdf#page=13|PDF p.13]]
