# 机器可验证的CDU安全程序：把操作步骤建成有版本的依赖图

## 核心结论

- 问题不是设备没有数字模型，而是程序步骤、隔离点、联锁、角色与来源依据未被同一模型表达，硬件变化后无法完整枚举受影响作业。 [[cooling-environments/Machine-Verifiable-CDU-Safety-Procedures-A-Worked-Extraction-from-OCP-Project-Deschutes.pdf#page=2|PDF p.2]]、[[cooling-environments/Machine-Verifiable-CDU-Safety-Procedures-A-Worked-Extraction-from-OCP-Project-Deschutes.pdf#page=6|PDF p.6]]、[[cooling-environments/Machine-Verifiable-CDU-Safety-Procedures-A-Worked-Extraction-from-OCP-Project-Deschutes.pdf#page=7|PDF p.7]]、[[cooling-environments/Machine-Verifiable-CDU-Safety-Procedures-A-Worked-Extraction-from-OCP-Project-Deschutes.pdf#page=9|PDF p.9]]、[[cooling-environments/Machine-Verifiable-CDU-Safety-Procedures-A-Worked-Extraction-from-OCP-Project-Deschutes.pdf#page=12|PDF p.12]]
- 方案在Brick基础上增加操作层并与ASHRAE223对齐；以Deschutes v1.0.0抽取为例，把故障、检测、应急程序、维护程序和共享隔离点串起来。 [[cooling-environments/Machine-Verifiable-CDU-Safety-Procedures-A-Worked-Extraction-from-OCP-Project-Deschutes.pdf#page=9|PDF p.9]]、[[cooling-environments/Machine-Verifiable-CDU-Safety-Procedures-A-Worked-Extraction-from-OCP-Project-Deschutes.pdf#page=10|PDF p.10]]、[[cooling-environments/Machine-Verifiable-CDU-Safety-Procedures-A-Worked-Extraction-from-OCP-Project-Deschutes.pdf#page=11|PDF p.11]]、[[cooling-environments/Machine-Verifiable-CDU-Safety-Procedures-A-Worked-Extraction-from-OCP-Project-Deschutes.pdf#page=12|PDF p.12]]、[[cooling-environments/Machine-Verifiable-CDU-Safety-Procedures-A-Worked-Extraction-from-OCP-Project-Deschutes.pdf#page=13|PDF p.13]]、[[cooling-environments/Machine-Verifiable-CDU-Safety-Procedures-A-Worked-Extraction-from-OCP-Project-Deschutes.pdf#page=14|PDF p.14]]
