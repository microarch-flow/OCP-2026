# Betting on the Network：Meta 的全栈开放 AI 网络

## 核心结论
- Meta 把 scale-up、scale-out、scale-across 放进共享硬件/软件栈，开放不是单个端口标准，而包含拓扑、FBOSS/SAI、传输协议和运维。[[executive-sessions/08_Betting on the Network Meta’s Case for Full-Stack, Open AI Networking .pdf#page=6|PDF p.6]][[executive-sessions/08_Betting on the Network Meta’s Case for Full-Stack, Open AI Networking .pdf#page=21|PDF p.21]][[executive-sessions/08_Betting on the Network Meta’s Case for Full-Stack, Open AI Networking .pdf#page=22|PDF p.22]][[executive-sessions/08_Betting on the Network Meta’s Case for Full-Stack, Open AI Networking .pdf#page=23|PDF p.23]]
- AI 网络可靠性需要与并行算法共同设计；PAFT 隔离小集群重启、checkpoint 和降低暴露通信量属于工作负载层策略，不能用链路可用性替代作业可用性。[[executive-sessions/08_Betting on the Network Meta’s Case for Full-Stack, Open AI Networking .pdf#page=14|PDF p.14]]
## 关键证据
- IcePack 是基于 ORv3-HPRv1 的液冷网络柜；IceCube/N-IceCube 102.4T 分别用 TH6/Spectrum-6，运行 FBOSS+SAI。[[executive-sessions/08_Betting on the Network Meta’s Case for Full-Stack, Open AI Networking .pdf#page=8|PDF p.8]]
- Flattened Planar Fabric 将加速器接到多 plane、移除 ToR、采用两层和 NIC 负载均衡，代价是交换机与主机控制平面需要配合。[[executive-sessions/08_Betting on the Network Meta’s Case for Full-Stack, Open AI Networking .pdf#page=9|PDF p.9]][[executive-sessions/08_Betting on the Network Meta’s Case for Full-Stack, Open AI Networking .pdf#page=10|PDF p.10]]
- Tahan 用 TH5 51.2T 和 FBOSS 为 MTIA300 提供 Ethernet scale-up；TH6 与 ESUN 兼容设计属于后续方向。[[executive-sessions/08_Betting on the Network Meta’s Case for Full-Stack, Open AI Networking .pdf#page=18|PDF p.18]][[executive-sessions/08_Betting on the Network Meta’s Case for Full-Stack, Open AI Networking .pdf#page=19|PDF p.19]]
## 指标与条件
- RBB 的 SRv6/FBOSS+SAI 由设计到生产称用 5 个月，随后长途和 TE/SDN controller 用 3 个月；这是 Meta 自述工程周期，不是通用部署承诺。[[executive-sessions/08_Betting on the Network Meta’s Case for Full-Stack, Open AI Networking .pdf#page=16|PDF p.16]]
- MetaRoCE 宣布支持 best-effort Ethernet、单 QP 多路径、乱序与 stream multiplexing；两套开源实现不等于硬件生产性能已验证。[[executive-sessions/08_Betting on the Network Meta’s Case for Full-Stack, Open AI Networking .pdf#page=23|PDF p.23]][[executive-sessions/08_Betting on the Network Meta’s Case for Full-Stack, Open AI Networking .pdf#page=24|PDF p.24]]
