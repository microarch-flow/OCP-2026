# Every Megawatt Counts：DSX MaxLPS 动态功率分配

## 核心结论
NVIDIA区分最大单节点性能Max-P与最大功率预算利用MaxLPS：按workload测得功率而非峰值额定预留，有机会在同一电力配额内放入更多rack。[[executive-sessions/21_Every Megawatt Counts The Path to Building AI Factories with DSX MaxLP.pdf#page=3|PDF p.3]][[executive-sessions/21_Every Megawatt Counts The Path to Building AI Factories with DSX MaxLP.pdf#page=4|PDF p.4]][[executive-sessions/21_Every Megawatt Counts The Path to Building AI Factories with DSX MaxLP.pdf#page=5|PDF p.5]]
## 关键证据
DPS闭环结合功率遥测、workload profile和设施事件；功率不足时按P2→P1→P0优先级降到floor，最后可停作业，因此“电力合规”不等于所有SLA永不降级。[[executive-sessions/21_Every Megawatt Counts The Path to Building AI Factories with DSX MaxLP.pdf#page=6|PDF p.6]][[executive-sessions/21_Every Megawatt Counts The Path to Building AI Factories with DSX MaxLP.pdf#page=7|PDF p.7]][[executive-sessions/21_Every Megawatt Counts The Path to Building AI Factories with DSX MaxLP.pdf#page=8|PDF p.8]]
## 指标与条件
- Kimi-K2.5 FP4、Dynamo TRT-LLM、8K输入/1K输出、GB200：GPU TGP1200→800W，provisioned rack120→90kW，作者称吞吐相同，120/90=1.33即33%更多rack。未给请求尾延迟，不能扩展到所有模型。[[executive-sessions/21_Every Megawatt Counts The Path to Building AI Factories with DSX MaxLP.pdf#page=4|PDF p.4]]
- 540kW示例从330kW实际使用到增加一柜后的425kW；210kW“搁浅”是静态预算余量而非已浪费的电能。[[executive-sessions/21_Every Megawatt Counts The Path to Building AI Factories with DSX MaxLP.pdf#page=5|PDF p.5]]
## 图表与架构
已核对p.3–8；p.7的>20%、5–20%、≤5%分配差额是示意算法阈值，无控制周期与动态稳定性证明。
## 关联与比较
与 [[knowledge/sources/src-6a803e49a956|SLA下能效]] 合读：释放provisioned watt、降低consumed joule、提高可售SLO吞吐是三个相关但不同目标。
## 不确定性与待验证
演讲列BMC Redfish延迟可靠性和快速streaming telemetry为挑战；需功率越限暂态、失联安全、租户公平、SLO与实际容量验收。Lambda引用表达采用/目标，不给具名规模实测收益。[[executive-sessions/21_Every Megawatt Counts The Path to Building AI Factories with DSX MaxLP.pdf#page=10|PDF p.10]][[executive-sessions/21_Every Megawatt Counts The Path to Building AI Factories with DSX MaxLP.pdf#page=11|PDF p.11]]
