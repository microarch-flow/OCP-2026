# Cisco Silicon One：跨 SONiC/FBOSS 的分层验证复用

## 核心结论
共同 SAI/SDK/BSP 能复用硬件与数据面验证，但不能把“同一芯片通过测试”当成整个 NOS 已具备生产能力。演讲把组件、单机角色、多节点生产拓扑仿真分成三道门，正好对应供应链验收责任的拆分。[[networking/01_Bridging the Gap Accelerating Open-Source Agility on Cisco Silicon One.pdf#page=10|PDF p.10]]

## 关键证据、指标与条件
- sonic-mgmt 在带邻居/PTF 的网络环境验证系统行为；FBOSS Agent HW/SAI 测试可单机环回；Link Test 则覆盖实体光缆、qsfp_service、FSDB、链路抖动与 warmboot。三套测试回答的不是同一个问题。[[networking/01_Bridging the Gap Accelerating Open-Source Agility on Cisco Silicon One.pdf#page=4|PDF p.4]]
- 复现实验不仅固定 SAI/SDK，还固定 CPU/BIOS/内核、模块固件、平台驱动、拓扑、时间条件及测试版本；“跨 NOS 复用”不等于忽略这些变量。[[networking/01_Bridging the Gap Accelerating Open-Source Agility on Cisco Silicon One.pdf#page=6|PDF p.6]]
- BSP、数据面、SAI 层复用高；控制面中等，管理 API 低。PFCWD 特别需要 FBOSS 适配验证；因此不能沿用页面“Latency is an ASIC property”推断端到端拥塞时延也与 NOS 无关。[[networking/01_Bridging the Gap Accelerating Open-Source Agility on Cisco Silicon One.pdf#page=11|PDF p.11]][[networking/01_Bridging the Gap Accelerating Open-Source Agility on Cisco Silicon One.pdf#page=12|PDF p.12]]
- Wedge400C/Q200 生产部署始于 2021；Wedge800C 25.6T、8501/8223 51.2T 是不同平台规格，未给新平台上线周期或测试通过率。[[networking/01_Bridging the Gap Accelerating Open-Source Agility on Cisco Silicon One.pdf#page=14|PDF p.14]]

## 不确定性与待验证
“加速集成”无前后工时数据。需索取相同硬件下不同 NOS 的 QoS/重启/遥测一致性矩阵，以及第三方 NIC/光模块的失败复现工件；不要把高测试复用率换算成性能或研发成本收益。
