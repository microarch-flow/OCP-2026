# Unified Telemetry for Next-Generation Rack-Scale Infrastructure

## 核心结论
Meta/AMD 的 Helios 案例表明：更高集成度移除外部 PCIe switch 这一诊断探针后，接口边界遥测必须成为 silicon 的设计契约；而遥测自身也必须限流、分层、可测开销，否则监控会制造它声称观测到的拥塞。[[ai-clusters/Unified Telemetry for Next-Generation Rack-Scale Infrastructure.pdf#page=4|PDF p.4]] [[ai-clusters/Unified Telemetry for Next-Generation Rack-Scale Infrastructure.pdf#page=5|PDF p.5]] [[ai-clusters/Unified Telemetry for Next-Generation Rack-Scale Infrastructure.pdf#page=6|PDF p.6]]

## 关键证据
- 高频 telemetry read 引起 partial-cache-line write，曾压满 CPU memory subsystem，产生与真实 workload 相似的 backpressure；作者报告 field/bring-up 观察，不提供完整原始 trace。[[ai-clusters/Unified Telemetry for Next-Generation Rack-Scale Infrastructure.pdf#page=6|PDF p.6]]
- 三层必须并存：in-band amd-smi；OOB Redfish/PLDM；低优先级、adaptive polling、core affinity、verbosity tier、OOB first 与 qualification safeguards。[[ai-clusters/Unified Telemetry for Next-Generation Rack-Scale Infrastructure.pdf#page=7|PDF p.7]]
- UALoE 每站四阶段：DF interface、encap/decap、transmit scheduler/PFC、Ethernet MAC。full/empty、credit、stall、tag 生命周期有助识别“积压在何处终止”。[[ai-clusters/Unified Telemetry for Next-Generation Rack-Scale Infrastructure.pdf#page=15|PDF p.15]] [[ai-clusters/Unified Telemetry for Next-Generation Rack-Scale Infrastructure.pdf#page=16|PDF p.16]]
- p.19 示例：NIC 经 PCIe DMA 大量写 HBM 是流量 aggressor，DF→HBM write queue 为 choke point，UALoE 与 XGMI 为受害者；UALoE 发 PFC 不足以判定网络是根因。[[ai-clusters/Unified Telemetry for Next-Generation Rack-Scale Infrastructure.pdf#page=19|PDF p.19]]

## 指标与条件
- production polling 约 1s，可放宽到 10s；debug 常规可到 500ms，集中小指标集可到十几毫秒级。均为本平台设计，不是普适推荐采样频率。[[ai-clusters/Unified Telemetry for Next-Generation Rack-Scale Infrastructure.pdf#page=9|PDF p.9]]
- 1,790 total bundles、1,729 HSIO bundle runs、52 compute test types、6 HSIO test categories 是作者验证活动规模，不是故障率/精度。[[ai-clusters/Unified Telemetry for Next-Generation Rack-Scale Infrastructure.pdf#page=13|PDF p.13]]
- proposed qualification gate：production polling 下 BusBW 下降 **>1%** 判失败。这是作者拟议门槛，非已批准 OCP 标准，也不是已测平台恰好损失 1%。[[ai-clusters/Unified Telemetry for Next-Generation Rack-Scale Infrastructure.pdf#page=21|PDF p.21]]

## 图表与架构
已看 p.6 观察者效应循环、p.17 station-level backpressure、p.19 跨接口归因表、p.21 倡议阈值。单 station 判别 wire-side pushback 后仍需跨接口比较才可定源/受害者。[[ai-clusters/Unified Telemetry for Next-Generation Rack-Scale Infrastructure.pdf#page=17|PDF p.17]] [[ai-clusters/Unified Telemetry for Next-Generation Rack-Scale Infrastructure.pdf#page=19|PDF p.19]]

## 不确定性与待验证
材料自述 OCP EMEA 2026→Global 2026 的进展。UALoE counter 已在 Helios 读出；PCIe/XGMI/memory-side 的部分计数器仍在 silicon/deep-debug 工具，未 always-on，不能称全边界统一遥测已量产。[[ai-clusters/Unified Telemetry for Next-Generation Rack-Scale Infrastructure.pdf#page=3|PDF p.3]] [[ai-clusters/Unified Telemetry for Next-Generation Rack-Scale Infrastructure.pdf#page=19|PDF p.19]] vendor-neutral schema、verbosity contract 与 OCP working group 仍为提案。[[ai-clusters/Unified Telemetry for Next-Generation Rack-Scale Infrastructure.pdf#page=20|PDF p.20]] [[ai-clusters/Unified Telemetry for Next-Generation Rack-Scale Infrastructure.pdf#page=21|PDF p.21]]
