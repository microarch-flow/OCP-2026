# ±400V／800V板载供电：共同模块规格与资格验证目标

> 原始题名：400V-800V-On-Board-Power-Delivery-Requirements。阅读范围：完整可提取文字（物理 PDF 共 14 页），关键引用图表另做视觉核对。

## 核心结论

- Google、Microsoft、Meta提出共同的高压板载电源模块与验证规范，目的是多源供应、通用footprint和动态负载质量；工作组目标在2H27提供规范，而非宣布现成量产统一标准。 [[ai-open-dc-power-distribution/400V-800V-On-Board-Power-Delivery-Requirements.pdf#page=3|PDF p.3]]、[[ai-open-dc-power-distribution/400V-800V-On-Board-Power-Delivery-Requirements.pdf#page=4|PDF p.4]]、[[ai-open-dc-power-distribution/400V-800V-On-Board-Power-Delivery-Requirements.pdf#page=12|PDF p.12]]
- 两条路线分别高压转50V以复用既有48V下游VR，或高压更靠近ASIC转12V；必须比较整个供电链，而非单级转换效率。 [[ai-open-dc-power-distribution/400V-800V-On-Board-Power-Delivery-Requirements.pdf#page=6|PDF p.6]]、[[ai-open-dc-power-distribution/400V-800V-On-Board-Power-Delivery-Requirements.pdf#page=7|PDF p.7]]、[[ai-open-dc-power-distribution/400V-800V-On-Board-Power-Delivery-Requirements.pdf#page=10|PDF p.10]]
- 模块化换取功率密度、冗余和多供应商弹性，讲者承认相对离散实现可能有小幅效率代价；文件没有提供可量化TCO。 [[ai-open-dc-power-distribution/400V-800V-On-Board-Power-Delivery-Requirements.pdf#page=8|PDF p.8]]、[[ai-open-dc-power-distribution/400V-800V-On-Board-Power-Delivery-Requirements.pdf#page=11|PDF p.11]]
