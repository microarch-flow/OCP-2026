# Meta IceCube 102.4T：铜飞线、混合液冷与机柜纤维管理

## 核心结论
102.4T 交换机的系统瓶颈已不仅是 ASIC：212G PAM4 铜飞线、液冷光模块和预布线机柜一起决定可部署性。IceCube 仍使用前面板 OSFP，并不因 PHY-less 就成为 CPO 或 LPO。[[networking/04_Meta 102.4T Ethernet Switch.pdf#page=2|PDF p.2]][[networking/04_Meta 102.4T Ethernet Switch.pdf#page=4|PDF p.4]]

## 关键证据、指标与条件
- TH6C、2OU、64 OSFP，128×800GE / 512×200GE 非阻塞规格，使用 2×800G DR4/FR4 模块；机柜是 ORv3-HPRv1。[[networking/04_Meta 102.4T Ethernet Switch.pdf#page=2|PDF p.2]]
- ASIC 与 OSFP 液冷约占 85%，其余 CPU/电源/BMC 约 15% 风冷；并联光口水路、BMQC、多区域漏液检测。不是整机 100% 液冷。[[networking/04_Meta 102.4T Ethernet Switch.pdf#page=4|PDF p.4]]
- 30/40°C 进水、约 6 LPM/刀片；“max typical”功率 3820W，明确配置为全 retimed 5nm DSP DR4 模块。63.3dBA 条件为 30°C/6000ft；不把不同环境噪声直接比较。[[networking/04_Meta 102.4T Ethernet Switch.pdf#page=9|PDF p.9]]
- 44 层 370×265mm 主板为多个平台共用；机柜 GTSW 8192 根 in-rack fiber，预布线由集成商执行，维护和布线占用是设计变量。[[networking/04_Meta 102.4T Ethernet Switch.pdf#page=7|PDF p.7]][[networking/04_Meta 102.4T Ethernet Switch.pdf#page=12|PDF p.12]]

## 图表与架构
已核系统架构、俯视图与功耗图。p.5 的 340m 是**所有差分对总长度**，不是单条 212G 铜链路可达 340m。p.9 把 dBA 与 pJ/bit 共用柱图标尺，仅保留正文明确数值，不提取模糊柱高当作精确能效。[[networking/04_Meta 102.4T Ethernet Switch.pdf#page=3|PDF p.3]][[networking/04_Meta 102.4T Ethernet Switch.pdf#page=5|PDF p.5]][[networking/04_Meta 102.4T Ethernet Switch.pdf#page=9|PDF p.9]]

## 关联与比较
[[knowledge/concepts/network-optical-integration]]：IceCube-N 预览采用 Spectrum6、100% PCB 走线，而 IceCube 用 flyover；表明同一 102T 级别可有不同板级实现，不宜断言 200G/lane 必然需要飞线或 CPO。[[networking/04_Meta 102.4T Ethernet Switch.pdf#page=11|PDF p.11]]

## 不确定性与待验证
没有流量负载下的功耗曲线、BER、故障率或采购价格。3820W/102.4Tb/s 可得约 37.3pJ/bit 的标称满容量比值，但不是业务有效吞吐能效实测；需要同光模块、端口利用率与冷却设施边界才能做 TCO 比较。
