# BMC本地Debug Gateway：省掉WAN细粒度往返但保留授权边界

> 阅读范围：已阅读本文件全部可提取文字（21页）。关键页已视觉核对：7, 9；不代表逐页视觉审核。

## 核心结论

- 方案把run-control/寄存器/trace的细粒度执行放BMC内DTC，远端发送高层intent，降低每条硬件操作跨WAN往返。[[systems-management/From-Lab-to-Fleet-A-Secure-Unified-Debug-Framework-for-Cloud-Systems.pdf#page=8|PDF p.8]]
- 安全模式需明确BMC是否可信：trusted BMC会话加密不同于不信BMC时的端到端或confidential-compute gateway；SPDM认证不替代debug scope授权。[[systems-management/From-Lab-to-Fleet-A-Secure-Unified-Debug-Framework-for-Cloud-Systems.pdf#page=9|PDF p.9]]
- System Debug v0.1方向统一可发现pipe/orchestration，厂商payload仍可私有；crash/bulk/register dump等另有标准负责。[[systems-management/From-Lab-to-Fleet-A-Secure-Unified-Debug-Framework-for-Cloud-Systems.pdf#page=12|PDF p.12]][[systems-management/From-Lab-to-Fleet-A-Secure-Unified-Debug-Framework-for-Cloud-Systems.pdf#page=13|PDF p.13]]

## 关键证据

- 原型为Cobalt200、DC-SCM1.2/Nuvoton BMC、TRACE32和JTAG/MIPI SPP/DoI3C。[[systems-management/From-Lab-to-Fleet-A-Secure-Unified-Debug-Framework-for-Cloud-Systems.pdf#page=1|PDF p.1]][[systems-management/From-Lab-to-Fleet-A-Secure-Unified-Debug-Framework-for-Cloud-Systems.pdf#page=6|PDF p.6]]
- 联合软件vUART/PC与硬件rail状态的boot-hang案例说明跨层证据价值，但不是大样本RCA验证。[[systems-management/From-Lab-to-Fleet-A-Secure-Unified-Debug-Framework-for-Cloud-Systems.pdf#page=10|PDF p.10]]

## 指标与条件

- p.7作者测量：单步local JTAG14 ms、local SPP10 ms、internet SPP4800 ms、internet BMC DTC25 ms；读寄存器分别0.3/0.2/40/21 ms；1 KB scan chain分别0.31/2/360/22 ms。网络图约20 ms RTT，未给重复次数/p99/加密配置，不能外推全debug提速。[[systems-management/From-Lab-to-Fleet-A-Secure-Unified-Debug-Framework-for-Cloud-Systems.pdf#page=7|PDF p.7]][[systems-management/From-Lab-to-Fleet-A-Secure-Unified-Debug-Framework-for-Cloud-Systems.pdf#page=8|PDF p.8]]
- p.18按500–2000次单步推算远端40分钟–2.7小时、DTC12–50秒及约190x；这是单步累计，不是测得整机MTTR190x。[[systems-management/From-Lab-to-Fleet-A-Secure-Unified-Debug-Framework-for-Cloud-Systems.pdf#page=18|PDF p.18]]
