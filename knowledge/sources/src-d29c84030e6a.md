# Tahan-An-Open-Ethernet-Based-Scale-Up-Switch-for-Meta-s-MTIA-Accelerators

## 核心结论
Tahan 是为 Meta MTIA300 训练加速器设计的开放 Ethernet scale-up switch，复用商用交换 ASIC 与 FBOSS 运营体系。价值主张是减少供应商锁定、控制成本/路线，而非提供推理性价比测试。[[ai-clusters/Tahan-An-Open-Ethernet-Based-Scale-Up-Switch-for-Meta-s-MTIA-Accelerators.pdf#page=5|PDF p.5]] [[ai-clusters/Tahan-An-Open-Ethernet-Based-Scale-Up-Switch-for-Meta-s-MTIA-Accelerators.pdf#page=12|PDF p.12]]

## 关键证据
当前平台使用 51.2 Tbps Tomahawk5、混合风/液冷、flyover cables 的 PHY-less 设计；32×800GE 向背板、32×800GE 前面板，部署于 ORv3-HPRv1。[[ai-clusters/Tahan-An-Open-Ethernet-Based-Scale-Up-Switch-for-Meta-s-MTIA-Accelerators.pdf#page=7|PDF p.7]] [[ai-clusters/Tahan-An-Open-Ethernet-Based-Scale-Up-Switch-for-Meta-s-MTIA-Accelerators.pdf#page=8|PDF p.8]] [[ai-clusters/Tahan-An-Open-Ethernet-Based-Scale-Up-Switch-for-Meta-s-MTIA-Accelerators.pdf#page=9|PDF p.9]]
同一 NOS 复用 IPv6 dataplane/interface routes、PFC/QoS；ECMP/dynamic load balancing 与 BGP 被关闭，提醒 scale-up 不是原封照搬 scale-out feature set。[[ai-clusters/Tahan-An-Open-Ethernet-Based-Scale-Up-Switch-for-Meta-s-MTIA-Accelerators.pdf#page=13|PDF p.13]]

## 指标与条件
- 当前域：16 accelerators，每个 8×800GbE、4 switches；每加速器**每方向** 6.4 Tbps，作者标 non-blocking。非有效应用 goodput，未扣协议/FEC/集体通信开销。[[ai-clusters/Tahan-An-Open-Ethernet-Based-Scale-Up-Switch-for-Meta-s-MTIA-Accelerators.pdf#page=10|PDF p.10]]
- 当前 fabric path：始终一跳，store-and-forward <1 µs/switch hop；两侧各约 1.5m twinax/~7ns。明确排除 NIC、PCIe、host software，不能作为端到端 all-reduce 或 token latency。cut-through -25% 标注 under exploration，非已交付指标。[[ai-clusters/Tahan-An-Open-Ethernet-Based-Scale-Up-Switch-for-Meta-s-MTIA-Accelerators.pdf#page=11|PDF p.11]]
- 下一代：72 accelerators，每个 24×400G、8 个 102.4Tbps Tomahawk6 switches，9.6Tbps/accelerator/direction、single hop，约为当前 1.5×。属于 next-gen 架构，未展示量产测试。[[ai-clusters/Tahan-An-Open-Ethernet-Based-Scale-Up-Switch-for-Meta-s-MTIA-Accelerators.pdf#page=14|PDF p.14]]

## 图表与架构
已核对 p.10/11/14 连接数、单向单位、排除项和 roadmap 标签。当前每加速器到每交换机 2×800G；下一代到每交换机 3×400G。可用于拓扑带宽算术，不足以证明拥塞下效率。
