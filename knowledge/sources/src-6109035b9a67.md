# Next Generation Optically Integrated Platform Solution for AI Data Centers

## 核心结论
Celestica 强调 CPO 只是使能技术，不是可运营的完整 fabric 方案。光学、网络软件、标准、遥测、故障隔离和可维护性要共同集成；这比只比较 pJ/bit 更接近机架商用条件。[[ai-clusters/Next Generation Optically Integrated Platform Solution for AI Data Centers.pdf#page=4|PDF p.4]] [[ai-clusters/Next Generation Optically Integrated Platform Solution for AI Data Centers.pdf#page=6|PDF p.6]]

## 关键证据
规模目标跨多机架；scale-up 与 scale-out 具有不同架构和运维要求。共同运营模型要贯通 optical 与 packet 层，并明确平台、网络运维、硬件团队的责任。[[ai-clusters/Next Generation Optically Integrated Platform Solution for AI Data Centers.pdf#page=3|PDF p.3]] [[ai-clusters/Next Generation Optically Integrated Platform Solution for AI Data Centers.pdf#page=8|PDF p.8]]
候选开放栈包含 SONiC、SAI、OCP switch platform/reference design、ESUN/UEC、CMIS for CPO/ELSFP 等；这是集成方向，不是已经完成全栈互通认证。[[ai-clusters/Next Generation Optically Integrated Platform Solution for AI Data Centers.pdf#page=7|PDF p.7]]

## 指标与条件
文中把 pJ/bit 作为 CPO 集成优势方向，但没有数值或比较基线；不得生成节能百分比。关键监测量包括温度、光功率、外置激光器状态、pre-/post-FEC BER。[[ai-clusters/Next Generation Optically Integrated Platform Solution for AI Data Centers.pdf#page=5|PDF p.5]] [[ai-clusters/Next Generation Optically Integrated Platform Solution for AI Data Centers.pdf#page=8|PDF p.8]]

## 图表与架构
本卡仅审阅文字；未核对图形细部，不据版面推断器件封装/光路。DS6005 页称基于 Broadcom Tomahawk 6 Davisson CPO，计划贡献 OCP、现场展台可见；“计划贡献”不等于已发布硬件规范。[[ai-clusters/Next Generation Optically Integrated Platform Solution for AI Data Centers.pdf#page=9|PDF p.9]]

## 关联与比较
[[knowledge/concepts/ai-infra-observability-contract]] 将它与 GPU 边界遥测连接：共同健康语义、清晰故障域和 serviceability 是运营闭环，而非链路带宽附属项。

## 不确定性与待验证
没有实测功耗、良率、可用性、激光替换时间、采购价或全寿命成本。作者称可靠性疑虑被消除，但本文未给原始证据；作为厂商观点保留，不做已证实结论。[[ai-clusters/Next Generation Optically Integrated Platform Solution for AI Data Centers.pdf#page=5|PDF p.5]] [[ai-clusters/Next Generation Optically Integrated Platform Solution for AI Data Centers.pdf#page=10|PDF p.10]]
