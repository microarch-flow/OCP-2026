# Redfish原生GPU可观测性：共享数据面、两类数字孪生

> 阅读范围：已阅读本文件全部可提取文字（15页）。未完成图表视觉核对；不把文字提取视作图形关系验证。

## 核心结论

- 作者区分设施/机架/服务器的infrastructure twin与按租户/工作负载组织的AI-cluster-aware twin：共用Redfish数据模型，但所有者、权限和目的不同。[[manageability-workshop/05_Redfish Native Fleet-Scale GPU Observability Assistant for AI Cluster .pdf#page=5|PDF p.5]]
- 运维价值是尽快排空/替换故障容量并保留RCA证据，而不是必须先完成诊断再恢复服务；训练同步与推理延迟SLO需要不同故障响应。[[manageability-workshop/05_Redfish Native Fleet-Scale GPU Observability Assistant for AI Cluster .pdf#page=3|PDF p.3]]
- 数字孪生为提议方向，租户角色与通用参考孪生尚未chartered，不能把演示当完成行业标准。[[manageability-workshop/05_Redfish Native Fleet-Scale GPU Observability Assistant for AI Cluster .pdf#page=13|PDF p.13]]

## 关键证据

- GYANAM参考实现演示热异常、VR rail漂移、间歇故障诊断包、工作负载诱发行为相关分析；PDF仅列演示步骤，不能替代视频观察。[[manageability-workshop/05_Redfish Native Fleet-Scale GPU Observability Assistant for AI Cluster .pdf#page=7|PDF p.7]][[manageability-workshop/05_Redfish Native Fleet-Scale GPU Observability Assistant for AI Cluster .pdf#page=8|PDF p.8]][[manageability-workshop/05_Redfish Native Fleet-Scale GPU Observability Assistant for AI Cluster .pdf#page=9|PDF p.9]][[manageability-workshop/05_Redfish Native Fleet-Scale GPU Observability Assistant for AI Cluster .pdf#page=10|PDF p.10]]
- 分层证据控制：默认事件/周期遥测 → 按需高频与诊断日志 → 设备crash dump/bulk telemetry；后两级部分仍WIP。[[manageability-workshop/05_Redfish Native Fleet-Scale GPU Observability Assistant for AI Cluster .pdf#page=12|PDF p.12]]
- 作者强调租户问题是授权范围而不只是transport；DSP0270可本地触达同一Redfish service，不自动提供租户隔离。[[manageability-workshop/05_Redfish Native Fleet-Scale GPU Observability Assistant for AI Cluster .pdf#page=12|PDF p.12]][[manageability-workshop/05_Redfish Native Fleet-Scale GPU Observability Assistant for AI Cluster .pdf#page=13|PDF p.13]]

## 指标与条件

作者观察rail telemetry常约1–10 Hz，足以慢漂移而不足以子周期瞬态；未给设备型号/测量样本，不能据此判定所有GPU管理接口上限。无MTTR、SLO改善或数字孪生预测精度实测。[[manageability-workshop/05_Redfish Native Fleet-Scale GPU Observability Assistant for AI Cluster .pdf#page=8|PDF p.8]]

## 关联与比较

与PLDM bulk telemetry、Redfish aliasing是上下游关系：前者提供可抓取证据，后者解决混合机群命名；统一schema仍不自动统一采样率、时间戳和租户授权。
