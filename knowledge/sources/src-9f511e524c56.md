# Oracle 大规模 AI 部署：800G LPO 现场数据与 1.6T 边界

## 核心结论
本材料给出罕见的大样本800G线性光现场数据：优化调参后LPO尾部BER和一月flap受影响比例低于FRO；但1.6T又转向LRO。这说明价值取决于代际、电通道和调参，不是“去DSP总能赢”。[[ocp-special-focus-photonics/Lessons-learned-from-GW-scale-AI-deployments.pdf#page=6|PDF p.6]][[ocp-special-focus-photonics/Lessons-learned-from-GW-scale-AI-deployments.pdf#page=7|PDF p.7]][[ocp-special-focus-photonics/Lessons-learned-from-GW-scale-AI-deployments.pdf#page=9|PDF p.9]]

## 关键证据、指标与条件
- 同ASIC、相同T0↔T1角色，24小时每链路最大pre-FEC BER，再跨链路求分布：156591 LPO-LPO median1.137e-11、p99 5.165e-10；202042 FRO-FRO median1.432e-11、p99 2.888e-8。**这是BER的跨链路p99，不是时延p99。**不同电损端口已优化调参，FRO含多DSP供应商。[[ocp-special-focus-photonics/Lessons-learned-from-GW-scale-AI-deployments.pdf#page=6|PDF p.6]]
- corrected-symbol/codeword的另一图样本仅LPO1022、FRO899，median3.1e-8 vs1.6e-7，不能套用359K大分母。一个月≥1次down-transition的链路比例3.244% vs5.681%，约1.75倍；不是flap事件总数倍率。[[ocp-special-focus-photonics/Lessons-learned-from-GW-scale-AI-deployments.pdf#page=7|PDF p.7]]
- 64×800G整机24小时平均输出功率分布：全FRO2184台median1528W，半FRO/半LPO1237台median1270W，差258W。32×约6W模块推算192W，余66W归因fan属于作者推断，未给独立风扇分表测量。[[ocp-special-focus-photonics/Lessons-learned-from-GW-scale-AI-deployments.pdf#page=8|PDF p.8]]
- p.8开头写50%LPO/50%LRO，但图例及其余正文写halfFRO/halfLPO，保留内部不一致，不能自行消除。[[ocp-special-focus-photonics/Lessons-learned-from-GW-scale-AI-deployments.pdf#page=8|PDF p.8]]
- 1.6T LRO：26dB channel、16W（10pJ/bit），3家DSP图平均BER2.72e-12 vsFRO8.41e-13；FEC bin p95为2 vs1。作者认为当前1.6T LPO互通/SI余量不足，这是其条件下判断。[[ocp-special-focus-photonics/Lessons-learned-from-GW-scale-AI-deployments.pdf#page=9|PDF p.9]]

## 图表与架构
已核4页数据与分母。p.6降序曲线虽标CDF，实际形状更像超过阈值比例；本卡以表格数值为准，不重构CDF。污染导致90% observed L1 failures、97%module replacements是Oracle归因统计，未给期间/样本，不能外推所有机房。[[ocp-special-focus-photonics/Lessons-learned-from-GW-scale-AI-deployments.pdf#page=11|PDF p.11]]

## 关联与比较
[[knowledge/concepts/network-optics-reliability]]：与Meta800G LPO现场观察方向一致，但指标/时期/光学配置不同，禁止合并失效率。EBO与自动化可针对污染，但“all but eliminates”不是已有零故障证明。[[ocp-special-focus-photonics/Lessons-learned-from-GW-scale-AI-deployments.pdf#page=12|PDF p.12]]

## 不确定性与待验证
CPO“最高50%省电”“30%+成本效率”是外部来源/理论量产预期，不是本现场实验。[[ocp-special-focus-photonics/Lessons-learned-from-GW-scale-AI-deployments.pdf#page=10|PDF p.10]] 需要同环境配对、部署年龄、事件排除规则、调参人力和维修工时，才能估算完整TCO。
