# Advancing Chiplet Flexibility: Updates in 2.0 OCE Transaction and Link Layer Specification

## 核心结论
OCE TLL 2.0 的关键不只是“支持更多 PHY”，而是 **包格式、credit 返回和 LLP 封装策略重新权衡效率、延迟与实现成本**。它不能被视为与 1.x 全栈透明兼容的升级：材料明确仅 link layer 有有限兼容模式。[[Server：Open Chiplet Economy/Advancing Chiplet Flexibility-  Updates in 2.0 OCE Transaction and Link Layer Specification.pdf#page=5|PDF p.5]]

## 关键证据
- Transaction layer 把 SoC bus（如 AMBA）映射为 TLP；link layer 加错误保护并切成 granules，PHY 负责实际传输。1.2 增加 BoW sideband 与 link-control protocol。[[Server：Open Chiplet Economy/Advancing Chiplet Flexibility-  Updates in 2.0 OCE Transaction and Link Layer Specification.pdf#page=3|PDF p.3]] [[Server：Open Chiplet Economy/Advancing Chiplet Flexibility-  Updates in 2.0 OCE Transaction and Link Layer Specification.pdf#page=4|PDF p.4]]
- 1.x 的 12-bit TLP 格式含 6-bit type、1 reserved、5 AUX；2.x 改为 4-bit type + 2-bit type extension，profile 决定 extension 用于扩展 type 还是 payload。[[Server：Open Chiplet Economy/Advancing Chiplet Flexibility-  Updates in 2.0 OCE Transaction and Link Layer Specification.pdf#page=6|PDF p.6]]
- Uncredited TLP 不再固定限制为每 LLP 一个，速率限制交给 profile。MSG 支持至 16-byte、按 byte 粒度的消息；CRD 有三种模式，含按 TLP type 的双 credit return、由 variant/profile 定义的多 credit 字段，以及无 credit 的 IDLE。[[Server：Open Chiplet Economy/Advancing Chiplet Flexibility-  Updates in 2.0 OCE Transaction and Link Layer Specification.pdf#page=7|PDF p.7]]
- 默认 24-granule LLP 为 1 header + 23 payload；16-granule（1+15）选项用于有限 1.x 兼容和更低延迟需求。[[Server：Open Chiplet Economy/Advancing Chiplet Flexibility-  Updates in 2.0 OCE Transaction and Link Layer Specification.pdf#page=8|PDF p.8]]
- UCIe RAW streaming 通过 FDI 映射；BoW.FLEXI 用 EXT0、FLEXI header 和 FLEXI ECC，取消 start bits；窄接口通常 TLP:LLP 为 1:1。不同 binding 不能套用同一封装开销。[[Server：Open Chiplet Economy/Advancing Chiplet Flexibility-  Updates in 2.0 OCE Transaction and Link Layer Specification.pdf#page=9|PDF p.9]]

## 指标与条件
这里只给协议结构，**没有实测 GB/s、ns 或 pJ/bit**。仅考虑 LLP header 时，理想载荷比例从 15/16=93.75% 到 23/24≈95.83%；这是本知识库的结构算术，不含 TLP header、ECC、空闲、credit、packing 和 PHY 开销，不能当端到端效率。较长 LLP 还可能增加等待/串行化延迟，材料没有量化。

## 图表与架构
已核对 p.3 分层路径和 p.4 独立 sideband 协议栈；p.6/p.8 文本图页明确上述位宽与 granule 数。**Variant 描述 bus protocol，Profile 定义接口实现选择，PHY binding 描述物理层映射**，在模型中应分开。[[Server：Open Chiplet Economy/Advancing Chiplet Flexibility-  Updates in 2.0 OCE Transaction and Link Layer Specification.pdf#page=10|PDF p.10]]

## 不确定性与待验证
这是规格更新演讲，不替代完整规范或 silicon 合规报告。需检查最终 2.0 规范的发布状态、具体 profile、granule 字节数、时钟/宽度、credit round-trip、buffer 深度与互操作测试，再比较 BoW、FLEXI 或 UCIe 的真实性能。
