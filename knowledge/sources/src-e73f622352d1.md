# 风扇可靠性资格：统一测试剖面、样本与持续监控

> 阅读范围：已阅读本文件全部可提取文字（9页）。未完成图表视觉核对；不把文字提取视作图形关系验证。

## 核心结论

- 作者指出供应商测试、样本量和应力剖面差异，使跨供应商可靠性无法同口径比较；解决方向是统一资格规范而非只比较标称寿命。[[Test & Validation/Fan Reliability Qualification- A standardized framework across the server fan supplier base.pdf#page=4|PDF p.4]]
- Meta称已在主要供应商部署统一测试，并增加供应商ORT持续监控，以覆盖量产一致性。[[Test & Validation/Fan Reliability Qualification- A standardized framework across the server fan supplier base.pdf#page=5|PDF p.5]]

## 关键证据

- 现场失效类型包括叶轮裂纹、电气短路、MLCC裂纹与焊接缺陷；未来不可热插拔风扇提高维修代价。[[Test & Validation/Fan Reliability Qualification- A standardized framework across the server fan supplier base.pdf#page=3|PDF p.3]]
- 统一规范补测试缺口、增加样本量并借鉴IPC-9591。热循环发现叶轮材料不一致，作者称转向PPS后机群可靠性稳定、减少AI产品维修停机。[[Test & Validation/Fan Reliability Qualification- A standardized framework across the server fan supplier base.pdf#page=5|PDF p.5]][[Test & Validation/Fan Reliability Qualification- A standardized framework across the server fan supplier base.pdf#page=6|PDF p.6]]
- 行动项包括机内应力/诊断套件和共同结果schema。[[Test & Validation/Fan Reliability Qualification- A standardized framework across the server fan supplier base.pdf#page=8|PDF p.8]]
