# SUE-T-An-Ethernet-transport-for-Scale-Up-Networking

## 核心结论
SUE-T 是面向 XPU 小事务 load/store/atomics 的低面积、低延迟 Ethernet scale-up 接口方案：把事务 packing/scheduling、UET semantics/RODL 可靠传输和 ESUN 紧凑转发头组合，而不是另一款已测量产交换机。[[ai-clusters/SUE-T-An-Ethernet-transport-for-Scale-Up-Networking.pdf#page=2|PDF p.2]] [[ai-clusters/SUE-T-An-Ethernet-transport-for-Scale-Up-Networking.pdf#page=4|PDF p.4]] [[ai-clusters/SUE-T-An-Ethernet-transport-for-Scale-Up-Networking.pdf#page=5|PDF p.5]]

## 关键证据
目标 shared memory、直接地址翻译、request/response 至少两个 traffic classes；单跳为 primary target，可扩多跳。[[ai-clusters/SUE-T-An-Ethernet-transport-for-Scale-Up-Networking.pdf#page=3|PDF p.3]] 事务采用流水和有限缓冲，打包提高线效，但缓冲等待与延迟需要权衡。[[ai-clusters/SUE-T-An-Ethernet-transport-for-Scale-Up-Networking.pdf#page=5|PDF p.5]]
SES 语义头 12B，支持 opcode、jobid、事务打包及地址压缩到 8B；单事务最大 16K-1 bytes。[[ai-clusters/SUE-T-An-Ethernet-transport-for-Scale-Up-Networking.pdf#page=6|PDF p.6]] RODL 累积 ACK、可靠有序，避免 bitmap tracking，可选重传或 LLR。[[ai-clusters/SUE-T-An-Ethernet-transport-for-Scale-Up-Networking.pdf#page=7|PDF p.7]]

## 指标与条件
- up to 4k XPUs 与 E2E <2µs **RTT** 都是 primary target；旁注无硬限制，RTT 影响 buffer size，并非测得平均/p99。
- 256B payload 线效 85%、1KB 96%；5nm **估计**面积：LLR-only <2mm²，含 6µs retransmission buffer 配置 <3mm²。未披露频率、端口速率、PPA flow、完整宏/PHY 边界或实硅样本。[[ai-clusters/SUE-T-An-Ethernet-transport-for-Scale-Up-Networking.pdf#page=3|PDF p.3]] [[ai-clusters/SUE-T-An-Ethernet-transport-for-Scale-Up-Networking.pdf#page=7|PDF p.7]]
