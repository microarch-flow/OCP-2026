# RoT身份刷新：证书续期与可翻新设备的秘密生命周期不同

> 阅读范围：已阅读本文件全部可提取文字（9页）。未完成图表视觉核对；不把文字提取视作图形关系验证。

## 核心结论

- 演讲区分证书续期与refurbishment：后者必须清除现场熵/客户秘密并重新配置，不能只换证书；材料称Caliptra2.x现状不支持所需两种路径。[[Security/Beyond Static Identity- Enabling Secure Certificate Refresh in Silicon Roots of Trust.pdf#page=3|PDF p.3]][[Security/Beyond Static Identity- Enabling Secure Certificate Refresh in Silicon Roots of Trust.pdf#page=4|PDF p.4]]
- 设计选择取决于是否信任制造时秘密。若不信任UDS/DOE，现场熵是独立信任来源；若信任，可用KDF+计数减少熔丝消耗。[[Security/Beyond Static Identity- Enabling Secure Certificate Refresh in Silicon Roots of Trust.pdf#page=2|PDF p.2]][[Security/Beyond Static Identity- Enabling Secure Certificate Refresh in Silicon Roots of Trust.pdf#page=6|PDF p.6]]

## 关键证据

- 复用FE fuses为AES key、TRNG新随机样本加密存flash方案有长期存储、强迫重认证、翻新需新AES key等问题，作者未把它列为无缺点最终方案。[[Security/Beyond Static Identity- Enabling Secure Certificate Refresh in Silicon Roots of Trust.pdf#page=5|PDF p.5]]
- 因ROM空间受限，提出把LDevID证书生成移至FMC、绑定FMC PCR并在翻新考虑HW/FMC版本；存储可靠性仍开放。[[Security/Beyond Static Identity- Enabling Secure Certificate Refresh in Silicon Roots of Trust.pdf#page=7|PDF p.7]][[Security/Beyond Static Identity- Enabling Secure Certificate Refresh in Silicon Roots of Trust.pdf#page=8|PDF p.8]]

## 指标与条件

现状四个64-bit FE fuse共256 bits，按一个block消耗。p.2把“collision probability”写为2^128，概率不可能大于1，可能指生日界工作量；本卡保留为原稿疑点，不将它当数学事实。[[Security/Beyond Static Identity- Enabling Secure Certificate Refresh in Silicon Roots of Trust.pdf#page=2|PDF p.2]]

## 不确定性与待验证

需明确不可逆擦除证明、KDF输入/域分离、rollback、断电原子性和flash可靠性；文件不足以给量产翻新安全保证。
