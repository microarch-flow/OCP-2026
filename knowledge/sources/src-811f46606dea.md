# ASRock Rack／Arm：推理平台交付与配置驱动 OpenBMC

## 核心结论
这份27页PDF是**多部分合集**：系统设计/Arm CPU平台、ASRock Rack开放机架，以及OpenBMC工程框架。可复用的工程洞见是把板卡差异留在配置与设备树，而不是每SKU复制固件代码。[[executive-sessions/46_Scaling AI Inference Infrastructure from Silicon to System presented b.pdf#page=1|PDF p.1]][[executive-sessions/46_Scaling AI Inference Infrastructure from Silicon to System presented b.pdf#page=15|PDF p.15]][[executive-sessions/46_Scaling AI Inference Infrastructure from Silicon to System presented b.pdf#page=18|PDF p.18]]

## 关键证据
- Arm AGI CPU规格主张：最多136个Neoverse V3核、每核2 MB L2、最高3.7 GHz、300 W TDP、96条PCIe6、CXL3.0；标称内存带宽6 GB/s/core、最多6 TB/芯片、DDR5-8800及<100 ns延迟。这里没有完整实测条件。[[executive-sessions/46_Scaling AI Inference Infrastructure from Silicon to System presented b.pdf#page=11|PDF p.11]]
- ASRock 2OU2N-ARM展示44OU/36节点、12条DDR5-8000 RDIMM、6个PCIe6 E3.S、OCP NIC3.0，配EDK II和OpenBMC。平台内存速率8000不应自动改为CPU上限8800。[[executive-sessions/46_Scaling AI Inference Infrastructure from Silicon to System presented b.pdf#page=14|PDF p.14]]
- `meta-asrockrack`按SoC层/共享服务层/板级overlay分离；`prjconfig.bbclass`生成头文件，设备树GPIO名称成为单一事实源。[[executive-sessions/46_Scaling AI Inference Infrastructure from Silicon to System presented b.pdf#page=18|PDF p.18]][[executive-sessions/46_Scaling AI Inference Infrastructure from Silicon to System presented b.pdf#page=19|PDF p.19]][[executive-sessions/46_Scaling AI Inference Infrastructure from Silicon to System presented b.pdf#page=20|PDF p.20]][[executive-sessions/46_Scaling AI Inference Infrastructure from Silicon to System presented b.pdf#page=21|PDF p.21]]
- 产线写入EEPROM chassis ID，u-boot选择设备树、BMC选择平台脚本，同一映像覆盖不同机箱；预格式化rwfs减少首次启动工序。[[executive-sessions/46_Scaling AI Inference Infrastructure from Silicon to System presented b.pdf#page=22|PDF p.22]][[executive-sessions/46_Scaling AI Inference Infrastructure from Silicon to System presented b.pdf#page=24|PDF p.24]]

## 指标与条件
“3–5倍CPU需求”没有此文件内可复核的工作负载推导。TFTP/NFS开发迭代称秒级对比刷写分钟级，但没有统一测试时间表，不应当作量化产能收益。[[executive-sessions/46_Scaling AI Inference Infrastructure from Silicon to System presented b.pdf#page=6|PDF p.6]][[executive-sessions/46_Scaling AI Inference Infrastructure from Silicon to System presented b.pdf#page=25|PDF p.25]]

## 图表与架构
p.8实际渲染有完整架构图，文本提取中的“image part not found”并不意味着该页图像不可读。p.18/22说明管理代码复用和运行时SKU识别分别发生在构建期与启动期。[[executive-sessions/46_Scaling AI Inference Infrastructure from Silicon to System presented b.pdf#page=8|PDF p.8]][[executive-sessions/46_Scaling AI Inference Infrastructure from Silicon to System presented b.pdf#page=18|PDF p.18]][[executive-sessions/46_Scaling AI Inference Infrastructure from Silicon to System presented b.pdf#page=22|PDF p.22]]

## 关联与比较
与MiTAC、HPE管理栈联读：标准化固件接口、配置生成与机架操作策略各是不同交付层；成熟度应靠覆盖率、回归和现场恢复来评价。

## 不确定性与待验证
源代码实现未在本任务独立审计；“配置与代码永不漂移”是理想目标，仍需schema校验、版本绑定、EEPROM异常和错误SKU保护。部分标准贡献明确“进行中/未来”，不能视为全部已正式发布。[[executive-sessions/46_Scaling AI Inference Infrastructure from Silicon to System presented b.pdf#page=12|PDF p.12]][[executive-sessions/46_Scaling AI Inference Infrastructure from Silicon to System presented b.pdf#page=20|PDF p.20]]
