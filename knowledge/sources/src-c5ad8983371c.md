# Disaggregated CXL Memory Architecture for Agentic AI: Dynamic Pooling, Sharing, and PNM Offloading

## 核心结论
30页包含三项不同机制：**Samsung/Pangaea弹性分配；XCENA/Maru共享与预取；Samsung–Marvell–XCENA近存计算**。应分别评价容量分配、数据共享和计算搬迁，不能把5.6×、7.1×、64×、3.35×串成同一系统的累计增益。

## 关键证据
### 1. Pooling：解决stranded capacity
固定slice无法跟随agent工作量变化；DCD样式动态增减容量让空闲tenant的资源回到pool。当前采用 **DCD emulation，先于原生CXL3.x DCD平台**，不是已验证原生DCD硬件实现。[[Server：Composable Memory Systems/Disaggregated CXL Memory Architecture for Agentic AI- Dynamic Pooling,  Sharing, and PNM Offloading.pdf#page=5|PDF p.5]] [[Server：Composable Memory Systems/Disaggregated CXL Memory Architecture for Agentic AI- Dynamic Pooling,  Sharing, and PNM Offloading.pdf#page=10|PDF p.10]] [[Server：Composable Memory Systems/Disaggregated CXL Memory Architecture for Agentic AI- Dynamic Pooling,  Sharing, and PNM Offloading.pdf#page=12|PDF p.12]]

Blackwell/双socket Xeon6747P平台，4×96GB RTX PRO6000每socket；DDR5 128GB×8ch/socket；Marvell CXL2.0 switch与Samsung MD220，修改版Linux6.14.5/LMCache，vLLM0.13。Long_Doc_QA/Llama3.1-8B FP16结果显示：工作集同时装入时RDIMM与CXL性能接近；超过RDIMM而仍能装入CXL时，后者避免recompute，图中最大约5.6×。图横轴无绝对KV容量，纵轴归一化，不是所有context的普遍加速。[[Server：Composable Memory Systems/Disaggregated CXL Memory Architecture for Agentic AI- Dynamic Pooling,  Sharing, and PNM Offloading.pdf#page=7|PDF p.7]] [[Server：Composable Memory Systems/Disaggregated CXL Memory Architecture for Agentic AI- Dynamic Pooling,  Sharing, and PNM Offloading.pdf#page=8|PDF p.8]]

### 2. Sharing与prefetch：同一数据不必每个worker重复持有
Maru将vLLM/LMCache接入共享CXL KV pool，control plane只移动metadata；“zero-copy”指避免host/network staging与副本fan-out，**不是GPU消费数据时链路零流量**。[[Server：Composable Memory Systems/Disaggregated CXL Memory Architecture for Agentic AI- Dynamic Pooling,  Sharing, and PNM Offloading.pdf#page=14|PDF p.14]] [[Server：Composable Memory Systems/Disaggregated CXL Memory Architecture for Agentic AI- Dynamic Pooling,  Sharing, and PNM Offloading.pdf#page=15|PDF p.15]]

InfiniteMemory以DRAM为hot/cache层、SSD为cold层；pin共享prefix，调度时prefetch已知KV blocks。CXL64B line与NAND4–16KB页不匹配，仅1K outstanding×64B=64KB在途不足以直接发挥10+GB/s SSD，需要MB级bulk预取。[[Server：Composable Memory Systems/Disaggregated CXL Memory Architecture for Agentic AI- Dynamic Pooling,  Sharing, and PNM Offloading.pdf#page=16|PDF p.16]] [[Server：Composable Memory Systems/Disaggregated CXL Memory Architecture for Agentic AI- Dynamic Pooling,  Sharing, and PNM Offloading.pdf#page=18|PDF p.18]]

### 3. PNM：把缩减型计算留在高带宽内存侧
p.22用Gen6×8 64GB/s外部链路对比4ch DDR5-8400合计268.8GB/s内部带宽；PNM只回传缩减结果。67.2%为Samsung内部expander能耗拆解中可被减少的数据路径部分，**不是实测整机节能率**。p.23 rack级20TB/2.7TB/s是内存系统汇总，不等于单GPU有效带宽。[[Server：Composable Memory Systems/Disaggregated CXL Memory Architecture for Agentic AI- Dynamic Pooling,  Sharing, and PNM Offloading.pdf#page=22|PDF p.22]] [[Server：Composable Memory Systems/Disaggregated CXL Memory Architecture for Agentic AI- Dynamic Pooling,  Sharing, and PNM Offloading.pdf#page=23|PDF p.23]]

NDC API统一device/context/memory/module/function，bind→alloc→copy→load→launch；PyTorch/OpenXLA/PrivateUse1集成仍in progress。[[Server：Composable Memory Systems/Disaggregated CXL Memory Architecture for Agentic AI- Dynamic Pooling,  Sharing, and PNM Offloading.pdf#page=26|PDF p.26]]

## 不确定性与待验证
多个子项目软件、模型、设备和容量条件不同；不能把所有结果绑定到同一配置。需要原始trace、warm-up/arrival模式、精度/质量损失、energy边界与多tenant共享隔离。p.3含Samsung通用法律/保密声明；此处仅对用户仓库已提供材料进行技术释义，不增加原文件之外信息。
