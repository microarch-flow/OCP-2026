# 03_AI-Native Edge MHS 1.0

## 核心结论
HPE/Intel的AI-Native Edge-MHS 1.0通过标准化HPM尺寸、安装与管理接口，在短深度1U/2U边缘服务器复用模块。它解决机械/平台集成，不是自动保证工业实时性、IP67或AI模型性能。[[ai-computing-continuum/03_AI-Native Edge MHS 1.0.pdf#page=4|PDF p.4]] [[ai-computing-continuum/03_AI-Native Edge MHS 1.0.pdf#page=5|PDF p.5]] [[ai-computing-continuum/03_AI-Native Edge MHS 1.0.pdf#page=12|PDF p.12]]

## 关键证据
Class N宽168mm、Class L宽295mm、长度可在250–365mm扩展；p.8以N365/N350/L260和181mm pitch说明共用安装孔/riser，支持单N、单L或双N机箱。[[ai-computing-continuum/03_AI-Native Edge MHS 1.0.pdf#page=8|PDF p.8]] [[ai-computing-continuum/03_AI-Native Edge MHS 1.0.pdf#page=9|PDF p.9]]
DC-SCM CFF为推荐位置；BMC-down实现仍需软件兼容DC-SCM CFF才符合该演讲所述条件。物理可装不等于管理软件兼容。[[ai-computing-continuum/03_AI-Native Edge MHS 1.0.pdf#page=9|PDF p.9]]

## 指标与条件
尺寸是接口约束，非性能指标。p.4“nanosecond response”、NEBS/IP67+ certifiable为需求/设计方向，未附系统认证或端到端响应测量。[[ai-computing-continuum/03_AI-Native Edge MHS 1.0.pdf#page=4|PDF p.4]]

## 图表与架构
已看p.7–9机械图及p.11 OAC比较。p.11出现600W air-cooled maximum、1000W/5000W/低于500W等不同上下文功率说法，未统一对象；不将5000W字样当当前单GPU真实TDP。新中间宽度HPM仍以问号呈现，尚属探索。[[ai-computing-continuum/03_AI-Native Edge MHS 1.0.pdf#page=10|PDF p.10]] [[ai-computing-continuum/03_AI-Native Edge MHS 1.0.pdf#page=11|PDF p.11]]

## 不确定性与待验证
作者称V1.0 released，本卡未外读正式规格；生产设计仍需正式CAD、连接器pinout、signal integrity、hot-plug、供电瞬态和认证报告，不从演讲图直接制板。[[ai-computing-continuum/03_AI-Native Edge MHS 1.0.pdf#page=12|PDF p.12]]
