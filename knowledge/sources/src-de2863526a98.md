# Beyond DRAM: Persistent Memory via Compute Interconnects for AI

## 核心结论
材料把 GPU-local hot KV、PCM warm KV 和 NAND capacity tier 分开，并提出计算互连上的 persistent memory pool。必须区分三类证据：**现有AliSCM的厂商测量、等成本KV-cache测试、Gen7/UALink下一代目标与估算**；不能混写成一项已经实现的系统。

## 关键证据
- 现有AliSCM被讲者描述为量产部署的CXL2.0 Type3 E3.S、256GB–1TB/module、PCM介质、断电持久化。CXL.mem接口64B操作不等于介质寻址粒度；表中AliSCM为128B，350ns读延迟、20/6.5GB/s读写。测量条件未完整披露。[[Server：Composable Memory Systems/Beyond DRAM- Byte-Addressable Persistent Memory via Compute Interconnects for AI.pdf#page=4|PDF p.4]]
- AliFlash路线图使用request coalescing/prefetch/fine-grained ECC，把内存语义映射到NAND；Gen7/CXL4.0目标100M IOPS@512B，对应51.2GB/s有效数据，100设备池的10B IOPS是**目标求和**，不是实测线性扩展。[[Server：Composable Memory Systems/Beyond DRAM- Byte-Addressable Persistent Memory via Compute Interconnects for AI.pdf#page=5|PDF p.5]] [[Server：Composable Memory Systems/Beyond DRAM- Byte-Addressable Persistent Memory via Compute Interconnects for AI.pdf#page=6|PDF p.6]] [[Server：Composable Memory Systems/Beyond DRAM- Byte-Addressable Persistent Memory via Compute Interconnects for AI.pdf#page=7|PDF p.7]]
- Sparse attention可以减少HBM active working set，却仍需保存完整primary KV；演讲假设约584B/token/layer、空间局部性弱、indexer→TopK→gather串行且0%prefetch收益。这与大块可预测prefix检索是不同访问形态。[[Server：Composable Memory Systems/Beyond DRAM- Byte-Addressable Persistent Memory via Compute Interconnects for AI.pdf#page=9|PDF p.9]]
- UALink方案让GPU load/store/atomic直接到PCM endpoint，HBM保留hot working set、UMX管理tiering。[[Server：Composable Memory Systems/Beyond DRAM- Byte-Addressable Persistent Memory via Compute Interconnects for AI.pdf#page=11|PDF p.11]]

## 指标与条件
**p.8是等成本L2比较，非等容量：32GB DRAM对128GB AliSCM。** Qwen3-8B/SGLang0.5.6，RTX PRO5000 48GB GPU memory，PCIe5；host为8ch DDR5-6400、512GB/socket；AliSCM为CXL2.0×8、2×256GB interleave，配置读写21/7GB/s；SSD层10/2GB/s。[[Server：Composable Memory Systems/Beyond DRAM- Byte-Addressable Persistent Memory via Compute Interconnects for AI.pdf#page=8|PDF p.8]]

| KV层级/负载 | req/s DRAM→SCM | P90 TTFT DRAM→SCM | 演讲报告变化 |
|---|---|---|---|
| HBM+L2；30users×30turns，500in/500out，约126GB KV | 0.35→0.56 | 86.31→44.24s | +58.3%，−48.7% |
| HBM+L2+SSD；90users×25turns，1024in/256out，约400GB KV | 0.40→0.67 | 233.18→149.31s | +66.3%，−36.0% |
吞吐小数已四舍五入，不能用显示值苛求重现报告百分比。指标为 **P90，不是P99**；等成本声称没有公开价格/BOM支持。

p.12下一代估算：相对local DRAM的latency0.4×、等warm-KV容量cost0.25×/power0.125×，均是设计估算，且页内明确写baseline access path待验证。不要据此宣称PCM介质比DRAM物理访问更快；端到端路径基线尚不清楚。512B粒度1.65×read amplification也依赖该页584B访问形态。[[Server：Composable Memory Systems/Beyond DRAM- Byte-Addressable Persistent Memory via Compute Interconnects for AI.pdf#page=12|PDF p.12]]

## 不确定性与待验证
需要端到端延迟的起止点、读写比例/队深、PCM耐久/写放大、共享池拥塞、p99与故障语义。下一代模型名称/需求柱图只记录来源主张，没有独立核验其模型配置和单位；容量/带宽比还需明确GB/TiB换算和时间维度，不能直接当无量纲效率。
