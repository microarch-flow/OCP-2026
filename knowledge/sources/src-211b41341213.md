# NAND 大擦除块如何改变 FDP 小 RU 的经济性

> 阅读范围：已阅读本文件全部可提取文字（8页）。关键页已视觉核对：4, 6, 7；不代表逐页视觉审核。

## 核心结论

Sandisk 的核心主张是：随着 QLC erase block 增大，为很多小 RU 同时保留写入保护和 SLC 缓存的代价可能超过小 RU 降低 WAF 的收益。结论限定于其 NAND、保护方案、开放 RUH 密度和容量利用率假设，不是“FDP 普遍无效”。[[storage/Increasing-Block-Sizing-Changes-Data-Placement-Economics.pdf#page=2|PDF p.2]][[storage/Increasing-Block-Sizing-Changes-Data-Placement-Economics.pdf#page=3|PDF p.3]][[storage/Increasing-Block-Sizing-Changes-Data-Placement-Economics.pdf#page=6|PDF p.6]][[storage/Increasing-Block-Sizing-Changes-Data-Placement-Economics.pdf#page=7|PDF p.7]]

## 关键证据

- 给出的两代例子由 TLC 约 22–36 MB/erase block 到 QLC 约 100–140 MB；这是结构与代际示意范围，不是所有 NAND 的固定规格。[[storage/Increasing-Block-Sizing-Changes-Data-Placement-Economics.pdf#page=2|PDF p.2]]
- 小 RU 的数据先获得 SLC+XOR 保护，QLC 写入并检查后才释放；不同 RUH 写入速率还要求 SLC pool 的 over-provisioning。[[storage/Increasing-Block-Sizing-Changes-Data-Placement-Economics.pdf#page=4|PDF p.4]]
- Direct Write 被定义为首次 QLC program pass 就可读，从而不需要用 SLC 缓存 host write data；这是演讲中的特定方案名称。[[storage/Increasing-Block-Sizing-Changes-Data-Placement-Economics.pdf#page=3|PDF p.3]]

## 指标与条件

p.6 以每 TB 100+ 与 200+ open RUH 画到 2030 年的 SLC cache 百分比曲线，属于预测，不能当作已测未来成本。减少 RUH 会影响性能，sub-block erase 会增加管理复杂性。[[storage/Increasing-Block-Sizing-Changes-Data-Placement-Economics.pdf#page=6|PDF p.6]]

p.7 的相对 Cost/TB 对照使用 FDP 90% fullness、conventional 80% fullness，并假定 2026 小 RU FDP 的 OP 很少；因此比较不是等填充率、等 NAND 配置的纯算法胜负。[[storage/Increasing-Block-Sizing-Changes-Data-Placement-Economics.pdf#page=7|PDF p.7]]

## 关联与比较

与高容量 QLC 的大 IU 路径互补：IU 是映射粒度，RU 是数据回收/放置单位，两者不可混为一谈。要把 host 数据寿命隔离、租户数、开放 RU 数、SLC 容量和写入可靠性一起纳入选型。

## 不确定性与待验证

缺少具体 NAND part、预处理、WAF、尾延迟、断电/编程失败实验与价格来源。2030 的“极不经济”是厂商预测，其他介质/保护实现可能改变结果。[[storage/Increasing-Block-Sizing-Changes-Data-Placement-Economics.pdf#page=6|PDF p.6]][[storage/Increasing-Block-Sizing-Changes-Data-Placement-Economics.pdf#page=7|PDF p.7]]
